# Dammastock — exports Web SEO

59 images préparées pour le portfolio et le site. Ratio conservé, JPEG qualité 90, bord long au maximum de 3 200 px. Le manifeste indique les 15 images de la sélection éditoriale (hero, grandes images, récit) ; les autres sont classées portfolio. Les métadonnées XMP ont été relevées et croisées avec la trace GPX : coordonnées, altitude, écart temporel et niveau de confiance sont fournis pour chaque image. Les originaux restent intacts dans le dossier source.
